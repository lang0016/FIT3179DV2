# Heading typeface

Lora variable font, distributed under the SIL Open Font License 1.1.
Downloaded from the Google Fonts repository on 20 October 2026:
https://github.com/google/fonts/tree/main/ofl/lora

The original `Lora[wght].ttf` is hosted locally as `Lora-variable.ttf`.
The unmodified accompanying licence is `OFL.txt`. Lora is used for headings;
Arial remains the body and quantitative-label typeface. No remote font request
is needed to view the page.
