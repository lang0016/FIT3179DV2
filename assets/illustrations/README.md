# Decorative farming artwork

`australian-farm.webp` is a conceptual Australian rural landscape generated with
OpenAI's image-generation tool on 18 October 2026 for this project's visual
presentation. It is an illustration, not a photograph of a specific farm or a
source of research evidence. The original generated PNG is retained outside the
repository; this WebP export is 260,664 bytes. No external image host is needed.

The small section motifs are decorative SVG line drawings embedded in
`index.html`. Decorative images are hidden from assistive technology; all data
remains in the separately labelled charts and tables.
